# רשימת בדיקות ידניות למשחק הזיכרון

## דף הבית (index.html)
- [ ] כותרת ותיאור נטענים ומוצגים בעברית.
- [ ] במקרה של פחות מ-8 מילים פעילות, מוצגת הודעת שגיאה נאותה ואין אפשרות ללחוץ על כפתור רמות.
- [ ] אם יש 8 מילים פעילות אבל פחות מ-16, הרמה "16 צמדים" חסומה להקלקה (disabled).
- [ ] קישור "טבלת שיאים" פעיל ולחיץ ומוביל ל-`leaderboard.html`.
- [ ] קישור "ניהול מילים" חבוי כברירת מחדל אלא אם המשתמש מחובר כמנהל.

## משחק זיכרון (game.html)
- [ ] מעבר ל-`game.html?pairs=8` פורס 16 קלפים בדיוק.
- [ ] כל קלף מתחיל במצב הפוך ("?").
- [ ] לחיצה על קלף ראשון מפעילה את הטיימר. הטיימר רץ רק כשהמשחק משוחק.
- [ ] לחיצה על אותו קלף פעם נוספת אינה עושה דבר.
- [ ] זוג לא נכון -> הקלפים נשארים פתוחים למשך שנייה אחת בלבד ואז נסגרים.
- [ ] זוג נכון -> הקלפים נשארים פתוחים לשנייה, מוצגת אנימציית העלמה והקלפים יוצאים מכלל שימוש (נעלמים / display:none).
- [ ] בזמן שמוצגים 2 קלפים לא ניתן ללחוץ על קלף שלישי ולשבש את המשחק.
- [ ] טיימר עוצר כשהמשחק מסתיים (נמצאו כל הזוגות).
- [ ] מודאל סיום מופיע, מציג את הזמן ואפשרות להכניס שם.
- [ ] הכנסת שם ריק או שם של אות אחת נדחית עם הודעת שגיאה.
- [ ] לחיצה על כפתור יציאה באמצע משחק פותחת מודאל התראה של אובדן התקדמות.

## טבלת שיאים (leaderboard.html)
- [ ] טאבים בין 8/16/24 עובדים וטוענים נתונים בהתאמה מ-Supabase.
- [ ] עיצוב הטבלה מותאם למובייל - לא יוצר גלילה אופקית רוחבית.
- [ ] הזמנים ממוינים באופן עולה (הנמוך/המהיר ביותר הוא מקום ראשון).

## התחברות וניהול (login.html, admin.html)
- [ ] הזנת פרטים שגויים ב-login מציגה הודעת שגיאה ידידותית מ-Supabase.
- [ ] רק משתמש שנמצא ב-`admin_users` מורשה לגשת ל-`admin.html`. כל משתמש אחר נזרק החוצה.
- [ ] רשימת המילים בניהול מוצגת באופן תקין.
- [ ] הוספת מילה חדשה תעבוד, המילה תופיע ברשימה לאחר רענון/הוספה.
- [ ] עריכת מילה קיימת פועלת.
- [ ] השבתת מילה (מצב פעיל -> כבוי) עובדת. מילים לא פעילות אינן נכללות בשליפת המילים של המשחק.
- [ ] חיפוש בזמן אמת בתיבת החיפוש בניהול פועל.

## עיצוב ומובייל
- [ ] כל הכפתורים הגדולים נוחים ללחיצה באצבע (מינימום 44px גובה/רוחב).
- [ ] האתר נראה מצוין ב-Dark Mode.
- [ ] תמיכה במסכים של טלפון סלולרי רגיל - אין אלמנטים שנחתכים החוצה.
- [ ] לא ניתן לבצע double tap-zoom במובייל שמשבש את המשחק בטעות.
